# Dockguard

Dockguard is a small command-line tool written in Go that checks Dockerfiles for potential issues and configuration mistakes.

I built this project because I love containers and often work with tools like Docker and Podman. Writing Dockerfiles can be challenging, especially when I'm unsure about image tags, accidentally using mutable image versions, or handling sensitive information in `ENV` instructions.

I created Dockguard to help me catch these mistakes, improve my Dockerfiles, and learn more about Go and container security along the way.
